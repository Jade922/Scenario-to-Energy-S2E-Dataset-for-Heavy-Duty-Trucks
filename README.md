# Scenario-to-Energy-S2E-Dataset-for-Heavy-Duty-Trucks
We presents a real-world Scenario-to-Energy (S2E) dataset collected from four heavy-duty trucks of geographically diverse operation in China, comprising labeled driving data.  The dataset integrates road terrain information, multi-lane traffic interactions, vehicle-operation data, and powertrain measurements within a unified framework.

This repository contains a **partial subset of the S2E dataset**, supporting research on commercial vehicle dynamics, energy consumption, control algorithms, autonomous driving and related topics.
